was never built). Platform v1.7.0 put the daily Hukamnama from Sri Harmandir Sahib live on

readers see no change inside the app. Rewrite this text before submitting a build that turns the
Hukamnama on. The App Store build is Gurmukhi-only. The text below is a draft for the owner's
approval before submission.
