# What's New — 1.4.7

```text
A calmer Reader, a gutka-style Nitnem, and a real Sehaj focus.

• One set of page controls: the bar at the bottom turns the page, and "Continues on Ang N" still shows when a shabad carries over.
• Reading options (AA): named text sizes with a Reset, clear switches, and Sehaj focus in its own card.
• Sehaj focus: only the Gurmukhi, with room to breathe. The bars step aside, and "Exit Sehaj" brings them back.
• Nitnem: short-line banis such as Jaap Sahib and Chaupai Sahib read like a gutka, two half-lines to a row, with the chhand headings set bold and centred.
• Clearer transliteration, and a quiet break between shabads.

The text of Sri Guru Granth Sahib Ji is unchanged.
```
